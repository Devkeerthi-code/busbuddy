# Accessibility

- **Labels**: every input has a visible label; icon-only buttons have an accessibility label (for example "Alert me when the bus is 5 minutes away").
- **Headings**: each screen title is marked as a header for screen readers.
- **Touch targets**: at least 48 px.
- **Contrast**: text colours meet WCAG AA on their backgrounds in both themes; status is never shown by colour alone (pills carry words like "3 min late").
- **Motion**: the gliding marker and sheet animations jump instantly when the system reduce-motion setting is on.
- **Keyboard**: on the web, all controls are reachable with Tab and show a visible focus ring.
- **Driver safety**: the driver screen needs one tap to start and a deliberate hold to end, so it can be used without reading while parked.
