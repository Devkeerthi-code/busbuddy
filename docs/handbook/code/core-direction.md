# `direction.ts`

**File:** `supabase/functions/_shared/core/direction.ts`

Morning and evening travel order.

- `inTravelOrder(stops, routeLength, period)` renumbers and re-measures stops for evening runs.
- `shapeInTravelOrder(shape, period)` reverses the line for evening runs.
