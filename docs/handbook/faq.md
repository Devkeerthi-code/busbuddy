# FAQ

**Does BusBuddy track students?**
No. Only the driver's phone shares location, and only during a trip.

**Why does the driver need Android?**
Reliable background location needs a native app with a foreground service. Browsers stop sending location when the screen turns off.

**Why not an iPhone app for drivers?**
The code would run on iOS, but most college drivers use Android, and building for iOS needs a paid Apple developer account.

**How accurate is the ETA?**
Usually within a minute or two once the bus is moving; it improves after a few days as trip history blends in. "Updated N s ago" always shows how fresh it is.

**What if the driver forgets to start the trip?**
Riders see "Leaves at 07:05" and no live position. The transport office sees the trip still scheduled in the fleet view.

**What if the driver forgets to end it?**
It ends automatically at the last stop, or after 30 minutes without a fix.

**Can one person be in two colleges?**
No. One membership per account keeps permissions simple. Leave one college to join another.

**Can I try it without a college?**
Yes: sign up on the web demo and join the fictional DEMO college with the student code in the README.
