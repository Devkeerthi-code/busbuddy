# Prepare a driver phone

**When:** Before a driver's first trip.

1. Install the Android app from the install page in the README.
2. Sign up, join with the driver code.
3. Tap Start trip once at the depot: allow location **"Allow all the time"** and notifications.
4. Exclude BusBuddy from battery optimisation (Settings → Apps → BusBuddy → Battery → Unrestricted). Brand-specific steps are in the README.
5. Lock the phone for 2 minutes and check a student phone still sees the bus move.
6. Hold to end trip.
