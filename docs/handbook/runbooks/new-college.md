# Onboard a new college

**When:** A transport office wants to start using BusBuddy.

1. The transport officer signs up and taps **Set up your college**.
2. Setup → Routes: add each route and tap stops on the map in order, morning direction (first pickup to campus). Name every stop the way students say it.
3. Setup → Buses: add bus numbers.
4. Setup → People: share the **driver code** with drivers; they install the Android app and join with it.
5. Setup → Trips: one trip per bus run (route, bus, driver, morning or evening, weekdays). Set the first departure time and tap **Fill times**.
6. Share the **student code** on the college group or notice board.
7. Do a dry run with one driver before announcing it to everyone.
