# Route editor

**File:** `src/app/admin/setup/route/[id].tsx` · **For:** Transport office

Place stops on the map in order and name them.

## On the screen

- Tap the map to add the next stop; drag order with Move buttons; name each stop.
- Follow the real road: use a recorded trip as the route shape.
- Delete this route.

## States

- Unsaved changes are marked; every stop needs a name before saving.
- Empty: "No stops yet".
