# Setup checklist

**File:** `src/app/admin/setup/index.tsx` · **For:** Transport office

A numbered checklist: routes and stops, buses, people and codes, trips, with how many steps are left before students can track buses.

## On the screen

- One card per step, marked done when it has data.
- Usage · last 30 days (counts only).

## States

- All done: "Everything is in place. Share the student code and drivers can start trips."
