# Trip editor

**File:** `src/app/admin/setup/trip/[id].tsx` · **For:** Transport office

Edit one timetable entry.

## On the screen

- Route, Bus, Driver, Morning or evening, Runs on (weekdays).
- "Running (turn off for holidays)".
- Leaves first stop at, then Fill times: fills each stop from distance at a typical 22 km/h; any stop can be adjusted by hand.
- Save trip; Delete this trip.
